# Development Setup & Workflow

## Prerequisites
- Node.js (LTS version)
- npm, yarn, or bun
- Expo CLI
- Expo Go app on your physical device (or iOS Simulator / Android Emulator)

## Installation
1. Clone the repository.
2. Run `npm install` to install dependencies.

## Running Locally
- Run `npx expo start` to start the Expo development server.
- Scan the QR code with your phone's camera (iOS) or the Expo Go app (Android) to load the app on your device.
- Press `i` to open in iOS simulator, or `a` to open in Android emulator.

## Contribution Guidelines
- Create feature branches from `main`.
- Ensure all new components follow the UI/UX guidelines.
- Test changes on both iOS and Android platforms when possible.
